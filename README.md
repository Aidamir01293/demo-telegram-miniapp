# Demo Telegram Mini App

Черновик Mini App для локального бизнеса: услуги → запись / заявка → уведомление админу.

Что будет в репозитории:
- Web App на HTML/CSS/JS
- интеграция с Telegram WebApp API
- сценарий «выбрал услугу → оставил контакт → заявка ушла»
